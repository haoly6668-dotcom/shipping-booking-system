## 环境与范围

Windows，Python 3.14.0，Flask 3.1.3，pyodbc 5.3.0，ODBC Driver 18，SQL Server 2025 Express 17.0.1145.4。本机正式演示库为 `HarborBooking`，测试库为 `HarborBooking_Test`。测试库独立增加唯一编号资源；不清空或覆盖正式演示数据。

实际部署对象：12 张业务表、14 个视图、8 个存储过程（含 1 个内部权限检查过程）、2 个触发器。初始化包含 8 个港口、6 艘船、20 个客户、24 个航次、83 张订舱及对应明细、状态历史、审计记录。

- 补齐 NULL JSON 输入校验；修改既有订舱时依据其真实航次加锁，拒绝换航次。
- 所有静态资源本地加载，补齐网站图标，浏览器完整流程无控制台错误。
- 本程序是本机课设演示：尚未进行公网部署、安全渗透、跨浏览器兼容或大规模负载性能验证；不声称支持生产并发容量。
